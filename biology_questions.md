### Question 1

Plants having parallel venation of leaves have this type of
root system
పత్రాలలో సమాంతర ఈనెల వ్యాపనాం కలిగిన మొకకలు ఈ రకమైన
వేరు వ్ావ్సథను కలిగి ఉాంటాయి.

1) Tap Root System తలిి వేరు వ్ావ్సథ
2) Main Root System ప్రధాన వేరు వ్ావ్సథ
3) Parallel Root System సమాంతర వేరు వ్ావ్సథ
4) Fibrous Root System గుబురు వేరు వ్ావ్సథ

**Answer:** 4
- **Hint:** Monocots (like maize, grass) show parallel leaf venation paired with fibrous root systems, whereas dicots have reticulate venation and taproots.
- **Memory Tip / Mnemonic:** PF vs RT: Parallel = Fibrous (Monocots); Reticulate = Tap root (Dicots).
